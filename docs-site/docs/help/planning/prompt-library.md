# Prompt library

The **Prompt library** has ready-made prompts for common media-buying tasks. Fill in a few details and send them to Claude.

Go to **Planning** → **Prompt library** in the sidebar.

---

## Find a prompt

- Search with **Search prompts...**
- Filter by **All**, **Analysis**, **Planning**, **Execution** or **Monitoring**

Examples include **Analyze my campaigns**, **Build media plan**, **Check pacing**, **Weekly performance report** and **Creative fatigue monitor**.

---

## Use a prompt

1. Click a prompt card.
2. Fill in the **Variables to fill in** (for example your brand name or date range).
3. Check **Files to upload in Claude**: some prompts work best with a file such as a brief or last month's report attached in Claude.
4. Review the **Full prompt**.
5. Click **Open in Claude** to start a Claude chat with the prompt, or **Copy prompt** to paste it into Claude or ChatGPT.

You need the Nerve connector set up in your AI assistant first. See [Connect Nerve to Claude](../connect-ai/claude.md) or [ChatGPT](../connect-ai/chatgpt.md).
